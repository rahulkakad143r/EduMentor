# EduMentor

EduMentor is a Flask-based school admission and child readiness platform designed for parents, teachers, schools, and admins. It helps track child assessment outcomes, generate school recommendations, support teacher observations, and manage admission workflows in a single SQLite-backed application.

## Features

- Parent registration and profile management
- Child assessment flow with scoring across multiple skills
- Teacher observations and recommendations
- School listing and recommendation engine based on location, syllabus, classes, rating, and readiness score
- Parent admission tracking and school application workflow
- Admin dashboards for managing parents, teachers, schools, and assessments
- SQLite database with seeded demo accounts and school data

## Tech Stack

- Python 3
- Flask
- SQLite
- Jinja2 templates
- Werkzeug password hashing

## Project Structure

- `app.py` — main Flask application and routes
- `db.py` — SQLite schema, seed data, and database helpers
- `templates/` — HTML pages for all user roles
- `static/css/style.css` — styling for the application
- `edumentor.db` — local SQLite database file
- `demo_logins.py` — helper script to create or refresh demo accounts

## Getting Started

1. Create and activate a virtual environment (optional but recommended):

   ```bash
   python -m venv venv
   .\venv\Scripts\activate
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the app:

   ```bash
   python app.py
   ```

   If the app is configured to run with Flask debug mode, you can also use:

   ```bash
   flask run
   ```

4. Open the app in a browser at:

   ```text
   http://127.0.0.1:5000/
   ```
